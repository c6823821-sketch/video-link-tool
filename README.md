# 视频工具箱 / VideoLinkTool

安卓端多平台链接处理工具，三个功能完全独立：

- **下视频**：下载无水印视频；如果是图集/实况，则保存全部图片、对应实况视频和图集音频。
- **下音频**：只提取音频，不保存整段视频。
- **转文字**：只输出文字，临时音频处理完成后不保留。

## 支持平台

| 平台 | 视频 | 图集 | 音频 | 转文字 |
|---|---:|---:|---:|---:|
| 抖音 | 支持，无登录 | 支持，无登录 | 支持 | 支持 |
| 快手 | 支持，无登录 | 支持，无登录 | 支持 | 支持 |
| 哔哩哔哩 | 支持，无登录 | 不适用 | 支持 | 支持 |
| 百度视频/好看视频 | 支持，无登录 | 不适用 | 支持 | 支持 |
| 今日头条/西瓜视频 | 支持，无登录 | 不适用 | 支持 | 支持 |
| 小红书 | 支持，无登录 | 支持，无登录 | 支持 | 支持 |
| 其他 yt-dlp 支持的站点 | 视站点而定 | 视站点而定 | 视站点而定 | 支持时可用 |

> “无水印”指下载平台提供的源文件。创作者自己烧录进画面里的水印或字幕，不做去水印处理。

## 手机使用

1. 安装 GitHub Actions 产出的 APK。
2. 粘贴分享链接，点输入框右侧叉号可一键清空。
3. 选择“下视频 / 下音频 / 转文字”，点开始。
4. 视频、音频默认保存到系统“下载”目录；图集、实况和对应音频保存到“下载/视频工具箱图集/作品标题”。

抖音支持视频、图集和实况；快手、小红书支持视频和图集；B站、百度视频、今日头条支持视频。

## 转文字说明

转文字使用离线 `Vosk Android + vosk-model-small-cn-0.3`，约 33MB 的语音模型已内置在 APK 中，安装后不需要另外下载。模型只用于“转文字”，不会在下视频/下音频时启动。

## 本地构建

要求：

- JDK 17
- Android SDK Platform 34
- Android Build Tools 34.0.0

命令：

```bash
./gradlew :app:assembleRelease
```

产物：

```text
app/build/outputs/apk/release/app-release.apk
```

## 第三方组件

- `youtubedl-android`：yt-dlp / Python / FFmpeg 的安卓封装，GPL-3.0。
- `Vosk Android`：离线 ASR 运行时，Apache-2.0。
- `vosk-model-small-cn-0.3`：小型中文离线语音识别模型。

## 进度、画质和更新

- 只有任务进行中才显示进度条和具体百分比，空闲和完成后自动隐藏。
- 输入框为空时右侧显示粘贴键，有内容时显示叉号。
- 同一个链接先下过视频后，再点下音频或转文字会复用本地视频，避免重复下载。
- 视频优先选择平台公开的 1080P/H.264 档位，不进行二次转码压缩。
- 如果某条 B站作品在无登录状态下平台只返回 720P，App 会显示平台实际返回的画质，不会强行放大或假装成 1080P。
- App 启动时会自动检查 GitHub Release；右上角更新图标出现红点时表示有新版本。
- 点右上角更新图标可手动检查；点“下载更新”后会在 App 内下载并安装。
